# Courier management service

This project was built as the final assignment for the course
[«Разработка микросервисов на Go»](https://stepik.org/course/248638/syllabus) by Avito on Stepik.
It is intended for learning and demonstration purposes only and is not meant for production use.

## Project Overview
Service-Courier is a microservice within a food delivery platform ecosystem.
It is responsible for the full lifecycle of couriers: from registration to automatic order assignment and activity monitoring.
